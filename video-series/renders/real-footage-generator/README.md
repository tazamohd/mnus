# 🎥 خط إنتاج اللقطات الحقيقية — Real-Footage Pipeline

أنتج `renders/demo-access-saudi-ar.mp4` (أول فيديو بالمنهجية الجديدة: دارجة سعودية + لقطات حقيقية من salisauto.app). الخط قابل لإعادة الاستخدام لأي فيديو قادم من الخطة.

## المكوّنات

| الملف | الوظيفة |
|-------|---------|
| `bridge.mjs` | جسر محلي `127.0.0.1:8787 → salisauto.app` — يمرر الطلبات عبر بروكسي الجلسة لأن كروميوم لا يستطيع الوصول للموقع مباشرة عبر النفق (شغّله أولاً وأبقه يعمل) |
| `record_flow.mjs` | يسجّل التفاعل الحقيقي على الواجهة العربية (Playwright + recordVideo): مؤشر فأرة مرئي مع نبضة نقر، تحويل اللغة للعربية، تنفيذ السيناريو (دخول ← اختيار دور ← لوحة التحكم ← تبديل دور)، ويكتب `rec/marks.json` بنقاط القطع الزمنية |
| `gen_caps02.mjs` | يولّد الكابشنات العربية RTL كصور PNG شفافة (كانفس + Noto Sans Arabic) + لوحة الخاتمة |
| `tts02.py` | التعليق الصوتي بالدارجة (`ar-SA-HamedNeural`) مع ملاءمة كل سطر لفتحته الزمنية، ودمج صوت مقدمة/خاتمة الشعار مع خلفية موسيقية هادئة |

## خطوات الإنتاج (كما نُفذت)

1. `node bridge.mjs &` ثم تحقق: `curl http://127.0.0.1:8787/`.
2. `node record_flow.mjs` → تسجيل webm + نقاط قطع. راجع الفيديو الخام واختر نوافذ اللقطات (شبكات إطارات مصغرة تساعد هنا).
3. قص المقاطع بالمدد المخططة (ffmpeg `-ss/-t`، مع `tpad` لتمديد لقطة قصيرة بتجميد آخر إطار).
4. المقدمة/الخاتمة من ملفات الشعار المتحرك (رفعها المالك) مُكبّرة إلى 1080p.
5. `node gen_caps02.mjs` و `python3 tts02.py` (يتطلب `SSL_CERT_FILE=/root/.ccr/ca-bundle.crt` داخل بيئة الجلسة).
6. دمج نهائي: concat للمقاطع ← تركيب الكابشنات (`-loop 1` لكل صورة + `overlay enable='between(t,a,b)'`) ← دمج الصوت.

## ملاحظات

- بيانات الدخول الظاهرة في الفيديو حقيقية من صفحة الدخول العامة للديمو (كلمة مرور مشتركة معلنة في الواجهة نفسها).
- النص المنطوق بالدارجة أقصر أحياناً من كابشن الشاشة — مقصود للملاءمة الزمنية (ممارسة دبلجة معتادة).
- الخطة المعتمدة لكل فيديو: مجلد [`../plans/`](../../plans/) (إكسل بأسلوب المالك، يُعبّأ ويُراجع قبل الإنتاج حسب `PLANNING-AR.md`).
