SALIS AUTO — the complete UI/UX & systems blueprint

Every screen, feature by feature and module by module. Every role, every route, every user-flow category — mapped against wireframes, data flows, system flows, entity relationships and the platform architecture. One reference for design, engineering and QA to build and verify against.

10 portals 24 RBAC roles 235+ routes 175+ modules 320+ tables 27 diagrams

SALIS AUTO is a multi-tenant automotive ERP for franchise garage networks — intake, diagnostics, workshop execution, parts & inventory, billing with ZATCA e-invoicing, HR, finance, franchise/enterprise management, plus AI, IoT/OBD and AR modules. This document is the canonical map of its front-of-house.

01 · Foundation

Design system

A monochrome, brand-anchored system. Dark theme is the default operational surface; a light mode is fully supported. Colour is spent on the brand blue gradient and on semantic state only — orange is reserved strictly for warnings.

Display & UI: system grotesque stack (Segoe UI / system-ui) for zero-latency, no-CDN rendering. Data & codes: monospace with tabular-nums so VINs, invoice IDs and money columns align.

04 · Architecture

System architecture

Full-stack TypeScript. React 18 + Vite SPA (wouter routing, TanStack Query, shadcn/ui) over an Express API with a hybrid router — modular server/routes/* take priority, legacy routes.ts is fallback. PostgreSQL via Drizzle ORM. Passport session auth. WebSockets for real-time. Integrations for payments, SMS, AI, calendar and ZATCA.

12 · Flows & scenarios

Edge & error states

Every screen ships four baseline states plus scenario-specific guards. These are handled by the shared ErrorBoundary, skeleton and empty components.

Loading

Skeletons matched to layout; no spinners on data tables. Optimistic UI on mutations.

Empty

Illustration + primary CTA (e.g. "No job cards yet — create one").

Error

Boundary catches render/API errors; retry action; never a white screen.

Offline

PWA cache serves last data; queued mutations sync on reconnect.

ScenarioGuard / UX
Permission denied (RBAC)403 → "You don't have access", hide nav item, server enforces
Concurrent bay startTransactional row lock; loser sees "Bay just taken"
Out-of-stock at issueBackorder path; auto-requisition; advisor notified
ZATCA rejectionInvoice → Rejected; correction workflow with field-level errors
Payment failureRetry, alternate method, keep invoice unpaid; no partial state
Appointment no-showAuto-flag after grace; slot released; SMS follow-up
Quote declined / partialLine-item approve; job scoped to approved items only
Session expirySilent refresh or redirect to login preserving return URL
Tenant leakagegarageId enforced on every query; cross-garage 404
